Two-panel portrait calibration figure labelled as a synthetic demonstration. Panel a, above, is a scatter plot of 48 paired synthetic observed and predicted values with a dashed one-to-one reference and a fitted line. Panel b, below, plots prediction residuals against observed values around a horizontal zero reference and reports synthetic RMSE and bias. The vertical layout contains the same values and mappings as the landscape version and is not experimental evidence.
